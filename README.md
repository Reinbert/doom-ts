# doom-ts

A TypeScript port of [Doom](https://github.com/id-Software/DOOM), based on [DOOM.ts](https://gitlab.com/tchandelle/doom.ts) by [Thomas Chandelle](thomas.chandelle@gmail.com).

This version of Doom is stripped off some features and provides a playable game experience as a package that can be included in any web application. The shareware version of Doom ([doom1.wad](https://doomwiki.org/wiki/DOOM1.WAD)) is included in this package.

View the README of the original [DOOM.ts](https://gitlab.com/tchandelle/doom.ts) project or the GitHub repository of [DOOM](https://github.com/id-Software/DOOM) for more information.

## Features

- **Playable Game**. Source code in [./src/doom/](./src/doom/)
- **Modern THREE.js Renderer Engine**: Play with either the legacy 2.5D rendering engine, or a modern 3D engine. Source code in [./src/doom/webgl/](./src/doom/webgl/)
